# Читаємість та відповідність стандартам коду
Виправлені проблеми:
Імпорти: прибрано імпорти «зірочкою» (from math import *, from collections import *), зайві/дубльовані імпорти та кілька інструкцій в один рядок.

Мутабельні аргументи за замовчуванням: виправлено помилку в process_numbers (замість z=[] тепер використовується None).

Дублювання коду: видалено зайві функції-дублікати (calcSum, CalcSUM, helper1, HELPER_1) — натомість використовується вбудована функція sum(). Видалено зайві копії змінних та викликів (arr / ARR, x, y, z / x2, y2, z2).

Сортування: замість повільних ручних реалізацій бульбашкового сортування та сортування вставками використано вбудовану ефективну функцію sorted().

Робота з файлами: замість небезпечних конструкцій без закриття файлів використано контекстний менеджер with open(...), а також замінено «лийковий» except: на конкретний FileNotFoundError.

Безпека словників (KeyError): функція format_user тепер безпечно обробляє словники, де можуть бути відсутні ключі (наприклад, у користувача Olga не було ключа 'City').

Глобальні змінні та зайва складність: прибрано невиправдане використання глобальних змінних (global TEMP, GLOBLFLAG), беззмістовні вкладені цикли та надлишкові перевірки на кшталт if True==True==True.

PEP 8 та читабельність: дотримано стилю snake_case для функцій та змінних, UPPER_CASE для констант, додано анотації типів та докstring-описи.
